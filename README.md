# Diplom_2 — API тесты для Stellar Burgers

## Описание

Этот проект содержит автоматизированные тесты для проверки API сервиса Stellar Burgers. Тесты написаны с использованием `pytest`, `requests` и `allure-pytest`.

## Структура проекта

- `tests/` — все тесты по эндпоинтам:
  - `test_user_registration.py` — регистрация пользователя
  - `test_user_login.py` — логин пользователя
  - `test_user_update.py` — изменение данных пользователя
  - `test_order_creation.py` — создание заказа
  - `test_user_orders.py` — получение заказов пользователя
- `data.py` — все тестовые данные и сообщения API
- `conftest.py` — фикстуры для подготовки и очистки данных
- `requirements.txt` — зависимости проекта

## Как запустить тесты

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите тесты:
   ```bash
   pytest --alluredir=allure-results
   ```
3. Сформируйте и откройте Allure-отчёт:
   ```bash
   allure serve allure-results
   ```

## Особенности реализации

- Все тестовые данные, сообщения и url вынесены в `data.py`.
- Фикстуры реализуют только сложную логику (создание/удаление пользователя), не возвращают примитивные данные.
- Каждый тест независим, данные создаются и удаляются для каждого теста.
- В каждом тесте проверяется и код ответа, и тело ответа.
- Для каждого теста используется аннотация `@allure.title`.

## Примечание

Если при регистрации уже существующего пользователя API возвращает 500 вместо 403 — это баг на стороне сервера. Тест ожидает 403, как указано в документации.
